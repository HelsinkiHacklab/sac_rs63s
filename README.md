# Scanned manuals for SAC RS63S planer / thicknesser

Since I could not find any copies elsewhere on the internet and the original manufacturer is now out of bussiness I present to you scanned copies of all documendation we have:

* Users manual, both english and finnish versions
* Electrical diagrams
* Spare part catalog, mostly useful for parts breakdowns
* TERSA knife change instructions for the monoblock cutterhead
* Manual for the VFD for the feed
* Some sales material

Most of the documendation should apply for both the RS63S and RS53S models.
